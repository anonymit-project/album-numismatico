# Privacidad y RGPD — requisitos iniciales

Documento de requisitos, no asesoramiento jurídico ni política publicada.

## Principios

- Colecciones privadas por defecto y aislamiento entre usuarios.
- Recoger solo datos necesarios para cuenta, colección y sincronización.
- Permitir exportar la colección y eliminar cuenta/datos.
- Documentar finalidad, base jurídica, conservación y proveedores externos.
- No enviar fotografías a servicios de IA sin información y consentimiento adecuados.
- El consentimiento para usar fotos para mejorar el sistema debe ser separado y opcional.
- Eliminar EXIF/GPS y otros metadatos innecesarios de las fotos subidas.
- No almacenar credenciales ni secretos en el cliente.
- Aplicar controles de acceso por usuario en backend y probarlos.

## Pendiente

Determinar proveedor, región de alojamiento, encargados de tratamiento, transferencias internacionales, plazos de retención, textos legales y mecanismo de consentimiento. Verificar condiciones de los planes gratuitos y de cualquier servicio de IA.
